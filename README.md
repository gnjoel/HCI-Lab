# 🧪 HCI Lab — Usability Testing Platform

A browser-based usability evaluation platform for the
Human Computer Interaction course at APIU.

## Live Demo
🔗 https://hci-lab.vercel.app

## Target System
🛍️ https://aiu-mart.vercel.app

## About
Students use this platform to conduct Heuristic Evaluation
and Think-Aloud Protocol sessions on AIU-Mart.
Supports 10 groups, auto-saves to localStorage, and
generates a printable group report.

## Course
Human Computer Interaction — Asia-Pacific International
University (APIU)
